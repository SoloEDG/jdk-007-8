# 夜航音乐工作室

安装：`npm install`

本地启动：`npm run dev`，访问终端显示的地址。

Docker 启动：`docker compose up --build -d`，访问 http://localhost:18027 。

## 跟随伴奏（Follow）

开启后用麦克风听取真人演奏，自动生成独立的低音（琴键）与鼓组轨道，与现有循环一起演奏。

- 麦克风音频只进入 `AnalyserNode` 做识别，**不接扬声器输出、不写入作品文件**，从信号链上避免回授与回灌。
- 识别结果先显示为候选和弦；候选在滑动窗口内连续稳定后，才在**下一小节边界**切换，短暂噪声不会把伴奏带跑。
- 分析时钟与播放拍钟通过最小二乘线性拟合（`fitClock`）持续校准，界面显示固定偏置（ms）。
- 输入中断或置信度持续不足时：先保持上一和弦一小节，再用一小节线性淡出，随后停止生成；其他轨道照常播放。
- “录制生成的伴奏”只记录**实际生成并播放过**的音符，按整循环对齐，一圈提交一次；未提交的片段在结束或关闭跟随时丢弃，已提交片段可在关闭跟随后原样回放。
- 跟随风格、调性范围、低音/鼓组目标轨随作品保存到本机；恢复作品时保持暂停，重新开启跟随需再次授权麦克风。
- 跟随录音未提交前锁定目标轨与轨道增删，保证一圈音符不会前后落到不同轨道。

## 验证

- 类型检查：`npm run typecheck`
- 生产构建：`npm run build`
- 逻辑测试（无需浏览器，用 esbuild 打包后在 Node 运行）：`npm run verify`
